# Lilja.FancyScrollView

Included in the Lilja package series.

This package is a customized version of [setchi/FancyScrollView](https://github.com/setchi/FancyScrollView) (licensed under the MIT License), extending it with custom inspector-based Edit Mode preview capabilities, type-safe cell prefabs, and standardized APIs.

## Installation

Add via `Plugins/Lilja/Package Management/Fix Lilja Package Paths to Relative` if imported as a local package.
